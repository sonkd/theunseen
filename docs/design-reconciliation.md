# Design Reconciliation

This document compares the Phase 2 prototype expectations with the current implementation.

| Prototype / Planning | Implementation |
| --- | --- |
| Torch radius 500px | Torch radius kept at 500px |
| Movement speed 280px/s | Movement speed kept at 280px/s |
| Corridors between rooms | Corridors implemented as seeded corridor placement |
| Overlay flip effect | Flip overlay still supported |
| OPTIONS UI available | OPTIONS UI kept |
| 5 maps planned | Implementation uses 4 maps plus Sun map |
| Daily/Favorites sections | Daily/Favorites removed from header |
| Map data from Tiled JSON | Map data is now generated by `npm run mapdata` into `public/map-data.json` |
| Shared palette across maps | Per-map palette data used |

## Notes

This reconciliation file is intended as the single truth to update future Claude design prompts. It explains what is preserved and what changed for Phase 2.
